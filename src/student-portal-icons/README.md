# Iconos del portal estudiantil

Guarda en esta carpeta las imágenes del menú lateral y escribe su ruta en el cuarto valor de cada elemento de `NAV`, dentro de `backend/public/student-portal-v2.js`.

Ejemplo:

```js
['home', '⌂', 'Inicio', '/estudiante-iconos/inicio.png']
```

Se recomienda usar PNG, WebP o SVG cuadrados y con fondo transparente. Si una imagen no existe o falla al cargar, ARMI conserva como respaldo el símbolo actual.
